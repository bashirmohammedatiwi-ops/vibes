# خطة VIBES Mobile — تطبيق واحد للزبون والمزوّد بلغة تصميم راقية أنيقة

**الفلسفة**: الفخامة من **خفض التعقيد** — لوحة أحادية اللون (حبر داكن + ذهبي شامبانيا واحداً فقط)، مساحات بيضاء سخية، طباعة كبيرة واثقة، ورسوم متحركة ناعمة كالحرير. لا زخرفة، لا ألوان متعددة — أناقة تُحس ولا تُلاحظ.

# أولاً: لغة التصميم "VIBES Élégance" 🥂

## اللوحة — ثلاثة نغمات فقط
| النغمة | اللون | الاستخدام |
|---|---|---|
| **الحبر Ink** | `#101114` → `#1A1C22` | الخلفية الأساسية (الوضع الداكن الافتراضي) والنصوص في الوضع الفاتح |
| **البورسلان Porcelain** | `#F7F6F3` (سطوح فاتحة) + رمادي محايد هادئ | الوضع الفاتح والسطوح |
| **الذهبي الشامبانيا** | `#C9A96A` + تدرج خافت `#E3C990 → #A8854F` | **اللون المميز الوحيد**: الأزرار الأساسية، التمييز، الشرائط النشطة، الإبرازات |

ألوان الحالة (نجاح/تحذير/خطر) تظهر **وظيفياً فقط** في الشرائح والنقاط — أبداً كزينة. لا شيء آخر يكسر الرتابة الأنيقة.

## الطباعة — بطل التصميم
- خط **Cairo** بأوزان 300–900: عناوين ضخمة خفيفة الوزن (Light كبير أنيق من Heavy صغير)، تباعد أحرف مدروس للعربية
- سلّم نصوص من 11 إلى 34، ارتفاع أسطر مريح، أرقام لاتينية أنيقة للأسعار بخط tabular
- كل شاشة تُفتح بعنوان مسرحَي كبير + سطر وصفي هادئ بالرمادي

## الشكل والارتفاع
- بطاقات بنصف قطر كبير (20–24) وحدود شعرية `0.5px` بشفافية منخفضة — لا صناديق ثقيلة
- ظلال طبقية ناعمة جداً (三层) + سطوح زجاجية خافتة `blur(24) بشفافية 6%` للمساحات العائمة فقط
- زخرفة خلفية واحدة مميزة: **حبيبات noise خفيفة** + فيلات تدرج ذهبي خافتة جداً تظهر عند الحركة (تلمح إليها ولا تراها)

## الرسوم والمؤثرات 🎨
- **Rive**: رسوم خطية أنيقة (line-art) بلون ذهبي على الحبر — Onboarding (خطوط ترسم نفسها)، حالات فارغة، نجاح الحجز (انبعاث خطوط ذهبية هادئ — لا كونفيتي صاخب)
- **انتقالات العناصر المشتركة**: صورة البطاقة تكبر وتصبح رأس صفحة التفاصيل (Hero flight) — التوقيع البصري للتطبيق
- **Parallax** متعدد الطبقات في رأس التفاصيل والبطاقة المميزة
- **حركة القلب**: عند المفضلة، القلب ينفجر بنبضة ذهبية هادئة + اهتزاز لمسي خفيف
- حركات دخول متتابعة (stagger 40ms) بمنحنى `easeOutCubic` — كل شيء يصل بهدوء ثقة
- Shimmer **ذهبي خافت** للهياكل، لا رمادي صارخ
- أيقونات خطية رفيعة (stroke 1.5) مخصصة للتصنيفات الثلاثة — مزرعة/قاعة/تزيين برسم يدوي راقٍ

## المكوّنات الأساسية (مكتبة موحدة)
`VibesButton` (ذهبي متدرج بلمعة حريرية + نسخة شبحية بحد شعري) · `GlassCard` · `InkSheet` (ورقة سفلية بمقبض ذهبي رفيع) · `StatusPill` (نقطة + نص) · `GoldRatingBar` · `ShimmerBox` · `EmptyCanvas` (Rive) · `HeroPropertyCard` · `DayPriceStrip` · `SectionHeader` (عنوان + خط ذهبي قصير)

# ثانياً: المراحل

## M1 — الأساس
- نظام التصميم أعلاه كاملاً (رموز + مكتبة ويدجت + سمات داكن/فاتح بمبدّل محفوظ)
- **موديلات مكتوبة**: Property موسّع (وسائط/مزايا/وضع حجز/أوقات شفت)، Booking، Payment، Review، User، Coupon، AvailabilityDay مع dayPrices، Amenity
- **Dio مقوّى**: 401 → تحديث refresh token → إعادة محاولة، طابور أثناء التحديث، رسائل أخطاء عربية
- **StatefulShellRoute** (go_router): تبويبات (الرئيسية/الاستكشاف/حجوزاتي/ملفي) بحفظ الحالة + حارس مصادقة + توجيه بالدور (PROVIDER → نافذة المزوّد)
- إكمال l10n بالكامل + مبدّل عربي/إنجليزي

## M2 — الاستكشاف
- **الرئيسية**: تحية مسرحية، شريط بحث زجاجي ناعم، بانرات راقية، تصنيفات بالأيقونات الخطية، "مميز" أفقي ببطاقات Hero Parallax، الأعلى تقييماً، قريباً منك (فرز مسافة)
- **الريلز** 🎬: تدفّق عمودي ملء الشاشة لفيديوهات 9:16 (الباك اند يعالجها) — تشغيل صامت تلقائي، واجهة شفافة نصف ذوبان: الاسم/المدينة/السعر/التقييم + قلب ومشاركة وزر "احجز الآن" ذهبي. لا فيديوهات؟ أجمل الصور بنفس الأناقة
- **البحث**: ورقة فلاتر أنيقة (مدينة/نوع/سعر/سعة/مزايا/تاريخ/فرز)، بحث فوري debounced، سجل حديث

## M3 — صفحة المكان (التحفة)
- **معرض متكامل**: صور + فيديو + **جولات 360°** (سحب/دوران — الـ 3D العملي) + تكبير PhotoView، تنقل أفقي بمناطق نقر شفافة
- رأس Parallax يذوب في المحتوى، أزرار عائمة (مشاركة/مفضلة)
- المزايا بأيقوناتها مصنّفة، **شريط أسعار الأيام** (يوم/شفت بأوقات المكان الخاصة)، خريطة مصغرة OSM، تقييمات + كتابة تقييم، بطاقة المالك
- شريط سفلي زجاجي: السعر الحي + زر حجز ذهبي
- **المفضلة بالحساب**: نموذج Favorite بالباك اند + مساراته + قلب متزامن

## M4 — الحجز والمدفوعات
- مسار منمّق: تاريخ/شفت واعٍ بالأسعار اليومية + ضيوف Stepper + **quote حي** + كوبون بتحقق فوري
- نجاح برسم Rive ذهبي هادئ + رفع إثبات دفع (كاميرا/معرض) + خط زمني للحالة + إلغاء + تقييم بعد الإكمال

## M5 — نافذة المزوّد 🏛️ (نفس الاهتمام والفخامة)
قشرة تنقل خاصة بخلفية حبر أعمق ولمسات ذهبية أوضح قليلاً (تمييز هوية المالك):
1. الرئيسية: KPIs أنيقة (إيراد الشهر/نشطة/معلّقة) + الوصولات القادمة
2. الحجوزات: فلاتر، تأكيد/إلغاء بسبب، اتصال/واتساب بالضيف
3. التقويم الشهري: حظر/فتح أيام لكل شفت
4. ممتلكاتي + **إضافة مكان متدرجة**: نوع → خريطة → تفاصيل ومزايا → أسعار وأوقات ووضع حجز (يدخل المراجعة تلقائياً)
5. الأسعار: قواعد أيام/مواسم + معاينة حية بتقويم ملون (`/api/provider/*` جاهز)
6. الأرباح: رسم شهري أنيق + التفاصيل
7. إدارة وسائط: رفع صور/فيديو/ريلز

## M6 — الإتقان
- FCM: تسجيل عبر `POST /api/devices` (جاهز) + تنقل للإشعارات — يتفعل فور المفاتيح
- Onboarding بخطوط Rive ذهبية + تخطي
- الملف: بياناتي، لغة، داكن/فاتح، إعدادات إشعارات، دعم واتساب
- أيقونة تطبيق وشاشة إطلاق متوافقتان مع الهوية
- اختبارات وحدات/ويدجت + `flutter analyze` نظيف + بناء APK للتحقق
