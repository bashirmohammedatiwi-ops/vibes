# VIBES Atelier — إعادة تصميم كاملة من الصفر (نقلة نوعية حقيقية)

## القرار الجوهري: الانقلاب من الداكن المسطح إلى «التحريري الفاتح الفاخر»

التدقيق أثبت أن الهوية الداكنة الحالية مستحيلة الإنقاذ بأناقة (تباين 2.4:1 مكسور، سطوح مسطحة، مؤثرات مزيفة). النقلة الحقيقية = **عكس الأساس**:

**من**: حبر داكن مسطح ببطاقات صناديق وتباين مكسور
**إلى**: **كانفس عاجي دافئ مضيء + بطاقات بيضاء بعمق طبقي حقيقي + زمردي عميق جرأة** — نفس عالم Airbnb Luxe وKinfolk: صور تنفجر جمالاً على الفاتح، طباعة واثقة ثقيلة لا هشة، عمق حقيقي بظلال طبقية

كل شاشة سيتغير شكلها الجذري لأن الكانفس نفسه يتغير. هذا هو الفرق "بمراحل".

## المحور 1: نظام Atelier الجديد كلياً (`atelier_theme.dart` بديل كامل)

### اللوحة
- **كانفس**: عاجي دافئ `#FAF8F4` (فاتح مضيء — كل التباينات تحل تلقائياً)
- **سطوح**: أبيض نقي `#FFFFFF` بظل طبقي مزدوج (ambient 40px + key 8px) — عمق حقيقي محسوس
- **حبر**: `#1A1712` دافئ للنصوص · ثانوي `#6B665C` · ثالثي `#A39D90`
- **الزمردي الجرئ**: `#0F5132` للأزرار والنصوص المميزة (تباين 8:1 على العاجي — ممتاز) · خلفيات نعناعية `#E8F3EE` للشرائح
- **لمسة ذهبية عسلية** `#B8860B` **للأسعار فقط** — تمييز السعر بثمنته

### الطباعة — ثقة لا هشاشة
- **عناوين ضخمة ثقيلة**: w800 بحجم 28–32 للهيرو، w700 للعناوين — لا وزن خفيف هش
- Cairo محسّن: heights مضبوطة لكل مستوى، أرقام tabular عالمياً

### الهندسة
- أنصاف قطر 16/20/24 (ناعم عصري) · حدود 1px `#EDE9E0` · ظلال مزدوجة طبقية
- **شريط تنقل عائم**: كبسولة بيضاء معلقة بهامش 16 + blur حقيقي + ظل — بدل الشريط الملصق

## المحور 2: مكتبة مكونات Atelier الجديدة كلياً
`VibesButton` (زمردي مصمت + scale 0.97 عند الضغط + توهج زمردي) · `AtelierCard` (بيضاء عمق طبقي) · `GlassPill` (زجاج حقيقي blur للنصوص فوق الصور) · `HeroCarousel` (بدوران تلقائي + مؤشر نقاط + Parallax) · `SkeletonCard` (هيكل متحرك يطابق شكل البطاقة) · `PriceTag` (ذهبي عسلي واضح) · `StarRating` (نجوم ذهبية متدرجة تنبض) · `MaisonChip` (حد 1px + نعناعي عند التفعيل) · `SectionHeader` (عنوان ثقيل + "عرض الكل" ذهبي)

## المحور 3: إعادة تصميم كل شاشة بالنظام الجديد

1. **Splash**: عاجي + VIBES حبري ضخم w800 + خيط زمردي يرسم + معين زمردي شفاف watermark
2. **Onboarding**: صور ملء الشاشة بتعتيم متدرج + عنوان أبيض ضخم + نقاط كبسولة
3. **Login**: كانفس عاجي + شعار معين زمردي + حقول بيضاء بظل ناعم + OTP مربعات تنبض
4. **شريط التنقل**: كبسولة عائمة بيضاء blur + أيقونات مع دائرة نعناعية للنشط + مؤشر نقطة
5. **الرئيسية**: هيرو كاروسيل ملء العرض بدوران تلقائي + مؤشر + تحية حبرية ضخمة فوقه + بطاقة بحث عائمة بيضاء → تصنيفات دائرية بحدود → أقسام بكروت أفقية → قائمة عمودية
6. **بطاقة المكان**: صورة 200px بزوايا 20 + GlassPill للتقييم فوقها + قلب زجاجي + سعر ذهبي عسلي واضح
7. **الريلز**: ملء الشاشة الحقيقي (viewport 1.0 بلا حواف) + شريط جانبي زجاجي موحد + زر حجز زمردي مصمت + زر كتم صوت
8. **البحث**: شريط علوي أبيض عائم + فلاتر Chips بنعناعي عند التفعيل + نتائج ببطاقات بيضاء
9. **تفاصيل المكان**: معرض ملء + عنوان ضخم حبري + صفوف مواصفات بيضاء مفصولة + خريطة حقيقية + شريط حجز أبيض عائم بـ blur + زر زمردي
10. **الحجز**: خطوات ببطاقات بيضاء منفصلة + ملخص بسعر ذهبي ضخم
11. **النجاح**: عاجي + دائرة زمردية تنبض + ✓ أبيض + تأكيد
12. **حجوزاتي/المقارنة/الملف**: بطاقات بيضاء بظل + حالات بنقاط ملونة واضحة
13. **المزوّد**: كانفس عاجي (نفس اللغة) + بطاقات بيضاء + رسوم أعمدة زمردية

## المحور 4: صفحات وخصائص جديدة
- **صفحة الإشعارات** + **صفحة الدعم** (الموجودتان) بإعادة تصميم Atelier
- **فلترة متقدمة**: ورقة سفلية ببنية أقسام + Chips
- **بحث محفوظ** (آخر 3) + **وضع توفير البيانات** + **مشاركة بطاقة PNG** بهوية Atelier
- **تحرير أسعار المزوّد من الجوال** (موجود — يعاد تصميمه)

## المحور 5: الأداء والحركة
- الحركة: spring physics (scale 0.97 ضغط، دخول متدرج 40ms، Hero transitions)
- كل مؤثر بلا blur ثقيل إلا الشريط العائم والزجاج فوق الصور — 60fps
- بعد كل دفعة شاشات: analyze + tests + معاينة Chrome حية للوضعين
